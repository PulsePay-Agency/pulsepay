# Local Setup & Environment

## Prerequisites
- Node.js v18+
- Rust toolchain (`wasm32-unknown-unknown` target)
- Stellar CLI

## CLI Commands
Ensure all workspace dependencies are resolved.

```bash
pnpm install
```

Start the frontend and indexer utilizing Turborepo.

```bash
pnpm dev
```

## Testnet Contract Invocation
You can query the deployed Soroban contract directly using the Stellar CLI.

```bash
stellar contract invoke \
  --id CBH3ATY3PU7MRK54BOLEHU2ANM67LXLALNR5TQP6MR44NFKOLLEFHRZW \
  --source pulsepay-deployer \
  --network testnet \
  -- \
  get_claimable_balance \
  --stream_id 1
```
