# Employer Onboarding

## Stream Creation
Employers utilize the PulsePay dashboard to provision capital. The UI constructs the XDR transaction targeting the `create_stream` function. Employers define the total capital, start timestamp, and end timestamp.

## Passkey Authentication
To execute the transaction, employers interact with the WebAuthn API. Upon initialization, a Passkey is bound to the employer's hardware enclave (Secure Enclave, TPM). 

Subsequent stream provisions require biometric verification, preventing unauthorized treasury disbursements while abstracting away raw private key management.

## Clawback Rules
If an employee is terminated, the employer invokes `cancel_stream`. The contract deterministically calculates the ledger-second the cancellation was executed, refunds the unaccrued capital to the employer's address, and locks the previously accrued payload for the worker to claim.
